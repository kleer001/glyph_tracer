Timing sandbox

Every scenario below is a real board resolved by src/board.js and played back by src/animate.js — the same code the game runs. Pick a cascade, drag the timing, watch it again. hold is a still beat after each step; stagger delays each piece by how far it sits from whatever fired; split beats plays the shoving and the clearing as two separate beats instead of at once. shrink runs on its own clock, so a piece can slide at one speed and vanish at another. The swap is a speed — milliseconds per cell travelled, floored so a one-cell swap is still visible — because any two cells can be swapped and that distance runs from 1 to about 8.

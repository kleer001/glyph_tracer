Throw it outward

A cleared cell throws its colour. Every grain travels along a ray from the cell it came from and nothing pulls it down — this board has no gravity, so a burst that arced downward would be the only thing on screen obeying a force the game does not have. Motion is polar: an angle that never changes, a radius that does.

This runs the game's own renderer — the same compositor, the same tile and glyph
  drawing, the same seeded deal — with the burst added as a fourth layer above ground,
  glyphs and selection. push is an outward acceleration and drag
  pulls each grain's speed toward push / drag rather than to a stop, which is
  what lets a burst pop hard and then keep creeping outward. Set push negative
  to make it fall inward instead.

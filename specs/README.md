# Specs

One file per piece of work not yet built. Each is a pre-code sketch: what it is, the
numbers it needs, where it attaches, and what would prove it done.

**A spec comes down when its feature plays.** From that point the running game answers
what the page was asking, and a page kept past that is a second copy of the code with
nothing checking it. Git history keeps it, and the decision it settled belongs in
`DECISIONS-JOURNAL.md`.
